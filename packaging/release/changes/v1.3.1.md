主题：快充、挂起与桌面注销修复

改善充电连续性和桌面会话稳定性。

## 更新

- **GPU**　修复大提交在入队前因内存分配失败而中断的问题，并修正 GPU 导入 UDMABUF 写回内存时的映射属性。

- **快充**　电荷泵按电芯温区调节充电，修复电池达到 40°C 即提前降流的问题。
- **插电与挂起**　接电空闲时默认保持唤醒，合盖锁屏。主动挂起时将充电交给固定 PD 档，具体档位取决于电源。
- **桌面注销**　修复 Mutter 在注销时释放待显示帧引起的崩溃。
- **音频会话**　采用 Ubuntu 正式发布的 WirePlumber 更新，修复退出时可能发生的崩溃。

## 升级须知

解压本版软件包和回退 ZIP 到同一目录。沿用升级指南中的整版升级命令，新仓库选 `piano-1.3.1`，`--previous` 选 `piano-1.3.0-rollback-1.3.1`。升级前关闭虚拟机，整组安装后重启。

## 已知限制

快充档位取决于充电器、线材和电芯状态。

Theme: Fast charging, suspend and desktop logout fixes

Improve charging continuity and desktop session stability.

## Changes

- **GPU**　Fix allocation failures before large GPU submissions reach the queue and correct the GPU mapping attributes for write-back memory imported from UDMABUF.

- **Fast charging**　The charge pump follows the battery cell temperature profile, fixing premature current reduction at 40°C.
- **External power and suspend**　By default, an idle tablet stays awake on external power and closing the cover locks it. On manual suspend, charging hands off to a fixed PD profile supported by the source.
- **Desktop logout**　Fix a Mutter crash when releasing pending frames during logout.
- **Audio sessions**　Include the Ubuntu WirePlumber update that fixes a shutdown crash.

## Upgrade notes

Extract the packages and rollback ZIPs into the same directory. Use the whole-release upgrade command in the upgrade guide with `piano-1.3.1` as the new repository and `piano-1.3.0-rollback-1.3.1` for `--previous`. Shut down virtual machines before upgrading and reboot after installing the complete batch.

## Known limitations

The charging profile depends on the adapter, cable and battery cell conditions.
