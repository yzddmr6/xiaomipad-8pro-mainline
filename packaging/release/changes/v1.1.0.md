日用与恢复更新：原生电池保护、紧急返回 Android、系统自检和 Waydroid 支持，内核升级到 Linux 7.2.15。

## 更新

- **电池保护**：在“设置 → 电源”开启“保护电池健康”，充到 80% 停止、降到 75% 恢复。开启后插电且未到上限时系统保持唤醒，以便按时停充，与 Android 一致；到上限、拔线或关闭保护后照常睡眠。
- **插电合盖只锁屏**：接着电源合上键盘盖时只锁屏熄屏、不进入睡眠，继续正常充电；用电池时合盖照常睡眠。
- **紧急返回 Android**：Ubuntu 无响应时，打开键盘盖同时按住音量上、下键 10 秒，校验镜像组后切回 Android 并重启；不依赖桌面，未保存的内容会丢失，合盖时不响应。
- **系统自检**：运行 `piano-check` 查看系统与硬件状态；`piano-check --markdown` 生成可直接贴进 issue 的摘要，不含设备序列号、无线地址、网络名和用户名。
- **Waydroid**：内核加入 Binder、策略路由和 legacy iptables，可安装 Waydroid 运行 Android 应用，[安装与设置](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/main/docs/WAYDROID.md)。
- **外接显示器**：拔下 USB-C 显示器后 USB 控制器正常恢复，随后插 U 盘或电脑线无需重启。
- **外设驱动**：按 Ubuntu 通用内核补齐 USB 与蓝牙键鼠、手柄、数位板、USB 网卡与串口、USB 声卡及常用文件系统的驱动。
- **内核更新**：升级到 Linux 7.2.15，纳入 GPU/GMU、温控、UFS、USB 网络、外接显示和 Wi-Fi 的通用修正，以及充电与 Type-C 错误处理的修正；插电睡眠时按充电器类型保持 5 V 充电。

## 已知限制

- Waydroid 只能软件渲染：官方镜像的 Mesa 还不支持本机 GPU。
- 开启电池保护且插电未到上限时，从菜单选择“挂起”不会睡眠，屏幕回到锁屏。
- 插电合盖后，按压键盘盖可能把屏幕点亮。

Daily-use and recovery update: native battery protection, emergency return to Android, a system self-check and Waydroid support, on Linux 7.2.15.

## Changes

- **Battery protection**: turn on “Preserve Battery Health” in Settings → Power to stop charging at 80% and resume at 75%. While it is on, the tablet stays awake when plugged in below the limit so charging stops on time, as on Android; it sleeps normally after reaching the limit, unplugging or turning protection off.
- **Cover close on external power only locks**: closing the keyboard cover while plugged in locks and blanks the screen without suspending, so charging continues; on battery the cover still suspends the tablet.
- **Emergency return to Android**: if Ubuntu is unresponsive, open the keyboard cover and hold both volume keys for 10 seconds; after validating its image set the tablet switches to Android and restarts. It does not depend on the desktop, unsaved work is lost, and it is ignored with the cover closed.
- **System self-check**: run `piano-check` for system and hardware status, or `piano-check --markdown` for an issue-ready summary without device serials, radio addresses, network names or user names.
- **Waydroid**: the kernel adds Binder, policy routing and legacy iptables, so Waydroid can run Android apps; see [installation and setup](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/main/docs/WAYDROID.en.md).
- **External displays**: after a USB-C display is unplugged the USB controller recovers, so a USB drive or computer cable works next without a restart.
- **Peripheral drivers**: the kernel now includes the Ubuntu generic kernel's drivers for USB and Bluetooth keyboards and mice, game controllers, drawing tablets, USB network and serial adapters, USB audio and common file systems.
- **Kernel update**: moves to Linux 7.2.15 with shared GPU/GMU, thermal, UFS, USB networking, external display and Wi-Fi corrections and charging and Type-C error-handling fixes; plugged-in sleep keeps 5 V charging matched to the charger type.

## Known limitations

- Waydroid uses software rendering only: the official images' Mesa does not support this GPU yet.
- With battery protection on and the tablet plugged in below the limit, choosing Suspend from the menu does not suspend; the screen returns to the lock screen.
- With the tablet plugged in and the keyboard cover closed, pressing on the cover can wake the screen.
