主题：一键更新与直供电

可从通知整组升级系统，从充电菜单暂停充电，并根据屏幕方向切换立体声声道。

## 更新

- **一键更新**：从这一版开始，发布通知里有“更新”按钮。点了之后平板自己下载新版的软件包、校验、列出会清掉什么，再整组升级，装完提示重启；安装失败时可以一键回退到上一版。全程不需要电脑和终端。
- **插着电直接供电**：充电菜单新增“暂停充电”开关。打开后不再给电池充电，由充电器给平板供电，电池不再反复充放，适合长期插电使用；重启后保持。充电器功率不够整机用时，电池会补上差额。
- **自动亮度按本机曲线**：自动亮度按 8 Pro 原厂的照度与亮度对照表调节，不再一下子钉到最亮，亮度滑块也能把屏幕调暗。
- **重启后亮度不变**：登录界面不再按默认的自动亮度把屏幕调亮，重启后保持关机前的亮度。
- **扬声器跟着屏幕方向**：四个扬声器按屏幕方向分配左右声道，横着竖着拿都对。
- **USB 光驱**：插上 USB 光驱可以直接读光盘，支持 ISO 9660、Joliet 和 UDF。
- **升级更稳**：新版软件包的配置脚本出错时，整组回退也能退回上一版；从更早的版本跳版升级时，自动取回系统原版软件包用作回退。

## 升级须知

打开发布通知，点“更新”，下载完成后检查清理预览，再点“安装”。按提示重启。需要回退时，打开“系统更新”，点“回退到上一版”，完成后重启。旧版通知只有“查看更新说明”时，首次升级请使用下方手工步骤。 手工升级使用 `piano-1.5.0` 和 `--previous piano-1.4.1-rollback-1.5.0`。

## 已知限制

- **一键更新**：之前的版本还没有更新器，这一次升级仍按升级指南的“整组升级（只用平板）”做一遍；装好这一版之后，以后的版本就能一键更新。
- **一键更新**：平板上的系统软件包很久没有更新时，一键更新会先提示在“软件更新器”里装完系统更新，再继续。

Theme: One-tap updates and charger power

Update the whole system from the release notification, pause charging from the charging menu, and keep stereo aligned with the screen.

## Changes

- **One-tap update**: from this release on, the release notification has an Update button. The tablet downloads the new release packages, verifies them, lists what will be removed, upgrades the whole set and asks for a restart; if the installation fails, one tap rolls back to the previous release. No computer or terminal is needed.
- **Run directly from the charger**: the charging menu has a new Pause charging switch. With it on, the battery is no longer charged and the charger powers the tablet, so the battery stops cycling, which suits a tablet that stays plugged in; the setting survives a restart. If the charger cannot cover the tablet's draw, the battery makes up the difference.
- **Automatic brightness on this tablet's curve**: automatic brightness follows the stock 8 Pro table of ambient light to brightness, so it no longer jumps to full brightness, and the brightness slider can dim the screen again.
- **Brightness kept across restarts**: the login screen no longer raises the brightness with the default automatic setting; a restart keeps the brightness from before shutdown.
- **Speakers follow the screen**: the four speakers take left and right from the screen orientation, so stereo is correct in landscape and portrait.
- **USB optical drives**: discs in a USB optical drive can be read directly, with ISO 9660, Joliet and UDF.
- **Sturdier upgrades**: a full rollback now returns to the previous release even when a new package's configuration script fails; when skipping releases, the original distribution packages are fetched to keep the rollback exact.

## Upgrade notes

Open the release notification and select Update. After the download, review the cleanup preview and select Install. Restart when prompted. To restore the previous release, open System Update, select Roll back to previous release, then restart. If the existing notification only offers release notes, use the manual procedure below for this first upgrade. For manual upgrades, use `piano-1.5.0` and `--previous piano-1.4.1-rollback-1.5.0`.

## Known limitations

- **One-tap update**: earlier releases do not have the updater yet, so this upgrade still follows the guide's full upgrade on the tablet once; from this release on, later releases install with one tap.
- **One-tap update**: if the tablet's system packages have not been updated for a long time, the update first asks you to install the system updates in Software Updater.
