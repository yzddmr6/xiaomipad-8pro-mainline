主题：外接鼠标和扩展坞重新能用，USB-C 触摸显示器也能触摸了

1.1.1 到 1.6.2 的 USB 主机模式不工作：接上鼠标、键盘、U 盘，或者扩展坞上的 USB 设备，都没有反应。这一版修好了。另外，USB-C 显示器或扩展坞把四条 USB 3 高速通道都用来传画面时，它上面的触摸屏和 USB 口现在也能用。

## 更新

- **USB 主机恢复**：从 1.1.1 起，接上鼠标、键盘、U 盘或扩展坞时，USB 控制器一直停在设备模式，这些 USB 设备没有反应；充电和连接电脑不受影响。原因是 USB-C 驱动把手写笔充电用的供电节点当成了 USB-C 接口，拿不到切换到主机模式的开关。现在它只认真正的接口。1.6.2 里“挂起唤醒后扩展坞上的设备重新识别”那项修复，也要到这一版才真正起作用。
- **USB-C 显示器和扩展坞上的 USB 设备**：显示器或扩展坞把四条 USB 3 高速通道都用来传画面时，原来连 USB 2.0 那对线也一起断开，它上面的触摸屏、USB 口和集线器都用不了。USB 2.0 本来就不占这四条通道，现在保持连通，这时那些 USB 口是 USB 2.0 速度。这项修复上游已经收下。
- **KernelSU 切换模块 v0.2.2**：模块信息里写明作者和项目地址。功能不变，已装的模块不用重装。
- **新装系统预装 GunyahVM 1.5.1**：已装的系统通过软件更新拿到。

## 升级须知

1.6.0 到 1.6.2 的用户：先关闭虚拟机，再在「软件更新器」里更新，或者运行 `sudo apt update && sudo apt full-upgrade`，完成后重启。

1.5.0 及更早的用户：先在平板上运行下面三行，接入签名源，然后重启。

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

## 已知限制

- 外接触摸屏要满足两条之一才会对应到它那块显示器：触摸设备的名称里有显示器的厂商或型号，或者它报告的物理尺寸和显示器相符。两样都对不上，或者触摸屏不报告尺寸时，触摸会落到平板屏幕上。

Theme: Mice and docks work again, and USB-C touch monitors now respond to touch

USB host mode did not work in 1.1.1 through 1.6.2: a mouse, keyboard or USB stick, or the USB devices on a dock, got no response. This release fixes it. In addition, when a USB-C monitor or dock uses all four SuperSpeed (USB 3) lanes for the picture, its touch screen and USB ports now work as well.

## Changes

- **USB host restored**: from 1.1.1, the USB controller stayed in device mode when a mouse, keyboard, USB stick or dock was plugged in, so these USB devices got no response; charging and connecting to a computer were not affected. The USB-C driver had taken the power node for stylus charging as a USB-C port and so never got the switch that puts the controller into host mode. It now only takes the real port. The 1.6.2 fix that re-detects the devices on a dock after suspend only takes effect from this release.
- **USB devices on USB-C monitors and docks**: when a monitor or dock used all four SuperSpeed lanes for the picture, the USB 2.0 pair was switched off too, so its touch screen, USB ports and hub did not work. USB 2.0 never uses those lanes and now stays connected; those ports then run at USB 2.0 speed. The fix has been accepted upstream.
- **KernelSU switch module v0.2.2**: the module information names the author and the project URL. It works as before, so an installed module does not need reinstalling.
- **New installations include GunyahVM 1.5.1**: installed systems get it through Software Updater.

## Upgrade notes

From 1.6.0 through 1.6.2: close your virtual machines, then update in Software Updater or run `sudo apt update && sudo apt full-upgrade`, and restart.

From 1.5.0 or earlier: run these commands once on the tablet to add the signed archive, then restart.

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

## Known limitations

- An external touch screen is mapped to its monitor only when its device name contains the monitor's vendor or model, or the physical size it reports matches the monitor. When neither matches, or the touch screen reports no size, touches land on the tablet's own screen.
