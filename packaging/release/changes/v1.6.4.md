主题：USB-C 外接显示器恢复出图，外接触摸屏对应外接显示器，合盖挂起不再卡住

本版修复 1.6.3 中 USB-C 外接显示器无画面、拔插后平板可能重启的问题，并使外接触摸屏的触摸落在外接显示器上；同时修复锁屏后合盖时系统长时间停在挂起准备、开盖不亮屏的问题。

## 更新

- **USB-C 外接显示器恢复**：1.6.3 中 USB-C 显示器无画面，原因是 USB-C 驱动与 DisplayPort 备用模式驱动同时控制 Type-C 切换开关。现由后者统一控制，两个插头方向均可出画面。
- **外接显示器拔插稳定性**：此前拔下占用四条高速通道的显示器后，USB-C PHY 停留在显示模式，再次插入时 USB 3 初始化超时，平板随即重启。现在拔下后 PHY 按请求切回，仅传画面时不再启动 USB 3。
- **外接触摸屏映射**：连接一台外接显示器时，USB 或蓝牙触摸屏的触摸映射到该显示器，登录界面同样适用。此前触摸屏的名称和尺寸与显示器均不匹配时，触摸落在平板屏幕上。
- **触摸修复内置到 GNOME Shell**：外接触摸屏映射和锁屏、弹窗中松手时的触摸报错修复直接做进 GNOME Shell，在登录界面、锁屏和桌面中始终生效。此前屏幕键盘防护以扩展形式提供，账户关闭“用户扩展”或使用自定义扩展列表时不会加载。
- **合盖挂起**：此前按电源键锁屏后随即合盖，系统可能停在挂起准备阶段长达 5 分钟，期间屏幕不亮，开盖和电源键均无响应。原因是锁屏动画被触摸或按键打断后，锁屏一直处于未完成状态，挂起始终等待它完成。现在准备挂起时直接完成锁屏，合盖后立即进入挂起。
- **挂起途中开盖**：开盖恰逢系统进入挂起时，挂起会被中止，不再在开盖状态下睡眠。
- **运行虚拟机时合盖**：GunyahVM 虚拟机运行期间合盖，平板锁屏并熄屏，虚拟机继续运行，闲置也不再挂起；关闭虚拟机后照常挂起。手动挂起仍会先关闭虚拟机，来不及关机的虚拟机（例如 Windows）会被强制停止，挂起前请先关闭虚拟机。
- **新装系统预装 GunyahVM 1.6.0**：已装的系统通过软件更新拿到。

## 升级须知

1.6.0 到 1.6.3 的用户：先关闭虚拟机，再在「软件更新器」中更新，或运行 `sudo apt update && sudo apt full-upgrade`，完成后重启。

1.5.0 及更早的用户：先在平板上运行以下三行接入签名源，然后重启。

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

Theme: USB-C external displays work again, external touch screens follow the external display, and closing the lid no longer stalls suspend

This release fixes the 1.6.3 regression in which a USB-C external display showed no picture and re-plugging it could restart the tablet, and maps touches on an external touch screen to the external display. It also fixes a stall in which the tablet stayed in suspend preparation after locking and closing the lid, and did not light up when opened.

## Changes

- **USB-C external displays restored**: in 1.6.3 a USB-C display showed no picture because the USB-C driver and the DisplayPort Alt Mode driver both controlled the Type-C switches. The Alt Mode driver now controls them alone, and both plug orientations show a picture.
- **Display re-plug stability**: unplugging a display that used all four high-speed lanes previously left the USB-C PHY in display mode, so the next plug timed out USB 3 initialization and the tablet restarted. The PHY now switches back as requested after unplugging and no longer starts USB 3 while it carries only the picture.
- **External touch screen mapping**: with one external display connected, touches on a USB or Bluetooth touch screen map to that display, on the login screen as well. Previously, when neither the touch screen's name nor its size matched the display, touches landed on the tablet's own screen.
- **Touch fixes built into GNOME Shell**: external touch screen mapping and the fix for touch errors on release in the lock screen and dialogs are now part of GNOME Shell and always apply, on the login screen, the lock screen and the desktop. The on-screen keyboard guard was previously an extension, which did not load on accounts with user extensions turned off or with their own extension list.
- **Lid-close suspend**: locking with the power button and then closing the lid could leave the system in suspend preparation for up to five minutes, with the screen dark and the lid and power button ignored. When a touch or key press interrupted the lock animation, the lock never completed, and suspend kept waiting for it. The lock now completes at once when suspend is prepared, and the tablet suspends as soon as the lid closes.
- **Opening the lid during suspend entry**: opening the lid just as the system enters suspend now aborts the suspend instead of letting the tablet sleep with the lid open.
- **Closing the lid with a VM running**: while a GunyahVM virtual machine runs, closing the lid locks the screen and turns it off, and the virtual machine keeps running; idle suspend is held off as well. Once the virtual machine is shut down, the tablet suspends as usual. An explicit suspend still shuts virtual machines down, and one that cannot finish in time, such as Windows, is stopped forcibly; shut virtual machines down before suspending.
- **New installations include GunyahVM 1.6.0**: installed systems get it through Software Updater.

## Upgrade notes

From 1.6.0 through 1.6.3: close your virtual machines, then update in Software Updater or run `sudo apt update && sudo apt full-upgrade`, and restart.

From 1.5.0 or earlier: run these commands once on the tablet to add the signed archive, then restart.

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`
