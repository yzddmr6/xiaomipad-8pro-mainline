主题：签名 APT 源

设备软件包改由签名 APT 源提供，Ubuntu 软件更新器和 `apt` 都能更新。

## 更新

- **系统更新**：项目的软件包放进签名 APT 源，APT 用项目公钥校验索引；软件更新器和 `sudo apt full-upgrade` 都整组升级。旧的一键更新和发布通知已删除。
- **内核**：系统级缓存（LLCC）的切片表改用社区提交到上游的 SM8750 修正，32 个切片全部与原厂配置一致；此前相机、视频用的几个切片与原厂不同。

## 升级须知

旧版用户首次接入时，在平板上运行下面三行，然后重启。

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

## 已知限制

1.5.0 的「系统更新」会在下载前提示 `release is missing required update attachments`。请使用上述命令接入。

Theme: Signed APT updates

Device packages now come from a signed APT archive; Ubuntu Software Updater and `apt` both update them.

## Changes

- **System updates**: project packages are published in a signed APT archive, and APT verifies its index with the project key. Software Updater and `sudo apt full-upgrade` upgrade the whole set together. The old one-click updater and release notice are removed.
- **Kernel**: the system-level cache (LLCC) slice table now uses the SM8750 fix submitted upstream, and all 32 slices match the stock configuration. Previously a few slices used by the camera and video blocks differed.

## Upgrade notes

On an existing installation, run these commands once on the tablet, then restart.

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

## Known limitations

The v1.5.0 updater stops before downloading and reports `release is missing required update attachments`. Use the commands above.
