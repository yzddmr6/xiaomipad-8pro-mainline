## 更新

- **开发者维护**：默认软件包移除旧 USB 调试控制台，远程维护使用开发者模式 SSH。

- **自动亮度**：自动亮度随环境光调整背光。

- **拍照补光**：“补光相机”应用支持拍照补光，完成或退出后自动关灯。

- **手写笔**：Focus Pen Pro 支持位置、压感、悬停与轻捏侧键。

- **虚拟机**：预装 GunyahVM 1.0.1 图形虚拟机管理器，并在 Dock 提供入口。

- **Android 网页**：为缺少 OMX 服务的 Waydroid 镜像提供覆盖修正，恢复网页和相关共享存储功能；[应用方法](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v1.2.0/docs/WAYDROID.md)。

## 已知限制

- 手写笔使用 120 Hz；笔身滑动手势尚未接入。

- 拍照使用连续补光，不提供与曝光信号同步的高功率闪光。

---

This release improves desktop input and photography while retaining Linux 7.2.15.

## Changes

- **Developer maintenance:** Default packages remove the legacy USB debug console; remote maintenance uses developer-mode SSH.

- **Automatic brightness:** Automatic brightness adjusts the backlight with ambient light.

- **Photo illumination:** Fill Light Camera supports photo fill light and switches it off after capture or exit.

- **Stylus input:** Focus Pen Pro provides position, pressure, hover and squeeze side-button input.

- **Virtual machines:** GunyahVM 1.0.1 graphical virtual-machine management is preinstalled with a Dock launcher.

- **Android web pages:** An overlay correction for Waydroid images with a missing OMX service restores web pages and related shared-storage functions; see the [application guide](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v1.2.0/docs/WAYDROID.en.md).

## Known limitations

- Stylus input uses 120 Hz; barrel slide gestures are not integrated.

- Photos use continuous fill illumination, without an exposure-triggered high-power strobe.
