⟦DRAFT:G-PACKAGE⟧
This release improves desktop input and photography while retaining Linux 7.2.15.

## Updates

⟦DRAFT:G-LIGHT⟧
- Automatic brightness adjusts the backlight with ambient light.

⟦DRAFT:G-FLASH⟧
- Fill Light Camera supports photo fill light and switches it off after capture or exit.

⟦DRAFT:G-PEN⟧
- Focus Pen Pro provides position, pressure, hover and squeeze side-button input.

⟦DRAFT:G-GUNYAH⟧
- GunyahVM graphical virtual-machine management is preinstalled with a Dock launcher.

## Known limitations

⟦DRAFT:G-PEN⟧
- Stylus input uses 120 Hz; barrel slide gestures are not integrated.

⟦DRAFT:G-FLASH⟧
- Photos use continuous fill illumination, without an exposure-triggered high-power strobe.
