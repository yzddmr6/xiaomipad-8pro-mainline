主题：内存紧张时不再卡住，GunyahVM 1.4.0

内存紧张时 GPU 和桌面不再卡住几分钟；GunyahVM 升到 1.4.0，虚拟机默认用足平板的 CPU、内存和 GPU。

## 更新

- **内存紧张时不再卡住**：内存紧张、GPU 又在忙的时候，比如开着虚拟机，桌面和虚拟机可能卡住几分钟，会话甚至会被系统结束，关机也走不完。现在 GPU 完成的通知不再等后台清理；回收内存时，桌面和应用的线程也不再等 GPU。
- **GunyahVM 1.4.0**：系统自带的 GunyahVM 升到 1.4.0。
  - 虚拟机默认用足平板：新建时用上全部 8 个处理器核心，内存最多可以分到宿主当前可用的量。
  - 新建的 Linux 虚拟机默认用原生 GPU，即 Turnip Vulkan，程序也能用 freedreno OpenGL。
  - 虚拟显示跟随面板刷新率，画面跟着桌面的节拍呈现。
  - 磁盘更快，宿主和来宾之间的网络也更快。
  - macOS 空闲时不再占满 CPU。
  - 在 8 Pro 上实测：来宾的 CPU 吞吐（SHA-256）是宿主的 97%；Linux 来宾的 virgl 画面帧率从 59 提到 83 帧/秒，是宿主的 70%；开着空闲的 macOS 时，整机功耗从 11.0 W 降到 7.5 W。
- **开虚拟机更省事**：
  - 低电量或发热降频时也能开虚拟机。
  - 开机后不用再先点“加载驱动”。
  - 已有的 Linux 虚拟机下次启动时自动用上新的来宾组件，开机不再多等约 2 分钟。

## 升级须知

1.6.0 用户：先关闭虚拟机，再在「软件更新器」里更新，或者运行 `sudo apt update && sudo apt full-upgrade`，完成后重启。

1.5.0 及更早的用户：先在平板上运行下面三行，接入签名源，然后重启。

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

## 已知限制

Linux 桌面来宾每次开机，都会按所选的图形模式登录对应的会话。在登录界面另选的会话，下次开机会被改回来。

Theme: No more stalls under memory pressure, GunyahVM 1.4.0

The GPU and the desktop no longer stall for minutes when memory runs low. GunyahVM moves to 1.4.0, and virtual machines use the tablet's CPU, memory and GPU in full by default.

## Changes

- **No more stalls under memory pressure**: when memory ran low while the GPU was busy, for example with a virtual machine running, the desktop and the virtual machine could stall for minutes. The system could even end the session, and shutdown could hang. GPU completion is now reported without waiting for background cleanup, and memory reclaim no longer makes desktop and application threads wait for the GPU.
- **GunyahVM 1.4.0**: the bundled GunyahVM is now 1.4.0.
  - Virtual machines use the tablet in full by default: new VMs get all 8 processor cores, and can be given as much memory as the host currently has available.
  - New Linux VMs use the native GPU by default (Turnip Vulkan), and programs can also use freedreno OpenGL.
  - The virtual display follows the panel refresh rate, and frames are presented in step with the desktop.
  - Disk access is faster, and so is networking between host and guest.
  - Idle macOS no longer keeps the CPU busy.
  - Measured on the 8 Pro: guest CPU throughput (SHA-256) reaches 97% of the host; the virgl frame rate of a Linux guest rises from 59 to 83 frames per second, 70% of the host; with idle macOS running, total power drops from 11.0 W to 7.5 W.
- **Easier VM start**:
  - VMs start even with a low battery or while the tablet is throttling.
  - After a restart, you no longer need to tap "Load Drivers" first.
  - Existing Linux VMs pick up the new guest components on their next start and no longer wait about 2 extra minutes at boot.

## Upgrade notes

From 1.6.0: close your virtual machines, then update in Software Updater or run `sudo apt update && sudo apt full-upgrade`, and restart.

From 1.5.0 or earlier: run these commands once on the tablet to add the signed archive, then restart.

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

## Known limitations

Linux desktop guests sign in to the session that matches the selected graphics mode at every boot. A different session chosen at the login screen is reset at the next boot.
