主题：滑动更跟手，虚拟机更快

默认的平衡模式下网页滑动、动画更跟手，性能模式真正优先响应；虚拟机的处理器下限从这一版起生效，图形性能约提高到原来的 3 倍。

## 更新

- **电源模式重做**：
  - 平衡（默认）：忙碌的处理器核心不再从最低频率慢慢爬升，最低保持在约 1.7 GHz；空闲的核心照常休眠。在 8 Pro 上实测（12 轮）：网页快速滑动的掉帧从 11.5 帧降到 5 帧，概览动画的第一帧从 90 ms 缩到 65 ms，glmark2 从 840 分提到 2612 分，空闲功耗测不出差别。
  - 性能：忙碌核心最低约 2.9 GHz，打开应用、滑动这类短时负载一开始就是高频。实测网页滑动掉帧 3.5 帧，概览首帧 61 ms，glmark2 3188 分；代价是滑动时整机多耗约 18% 的电，GPU 满载时多约 47%。
  - 省电：带处理器下限的任务（例如虚拟机）不再全挤到两个大核上；模拟这类负载时，整机功耗从 3.9 W 降到 3.3 W。
  - 音频、合成器这类实时线程不再被默认拉到最高频率。
- **虚拟机更快**：GunyahVM 给虚拟机线程设的处理器下限从这一版起生效。8 Pro 上 Linux 来宾的 glmark2 在平衡模式下从 313 分提到 952 分，性能模式下 1869 分，高于宿主在平衡模式下跑同一测试的 1344 分。
- **新装系统预装 GunyahVM 1.5.0**：已装的系统早已通过软件更新拿到。
- **内核**：
  - 挂起时如果某个驱动卡住，系统会在约一分钟后自动重启，不再停在黑屏、只能长按关机。
  - 打开 UFS 存储的内联加密引擎，文件系统加密（fscrypt）可以交给硬件做。
  - 蓝牙 RFCOMM 串口和网络共享（PAN）的过滤器，与 Ubuntu 的内核一致。
  - 读写存储更省处理器：读取速度不变，随机读时整机 CPU 占用少约 17%，顺序读时少约 64%。

## 升级须知

1.6.0、1.6.1 用户：先关闭虚拟机，再在「软件更新器」里更新，或者运行 `sudo apt update && sudo apt full-upgrade`，完成后重启。

1.5.0 及更早的用户：先在平板上运行下面三行，接入签名源，然后重启。

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

## 已知限制

平衡和性能模式都不再限制大核的最高频率，但大核 4.2 GHz 和 4.32 GHz 两个睿频档这一版还用不上：调频最高只请求到 4.09 GHz。

Theme: Smoother scrolling, faster virtual machines

Scrolling and animations keep up better in the default Balanced mode, and Performance now puts responsiveness first. The CPU floor GunyahVM sets for virtual machines takes effect from this release, which roughly triples guest graphics performance.

## Changes

- **Power modes reworked**:
  - Balanced (default): busy CPU cores no longer climb slowly from their lowest frequency; they stay at about 1.7 GHz or above, and idle cores still sleep. Measured on the 8 Pro over 12 rounds: dropped frames in a fast web fling fall from 11.5 to 5, the first frame of the Overview animation from 90 ms to 65 ms, and glmark2 rises from 840 to 2612, with no measurable change in idle power.
  - Performance: busy cores run at about 2.9 GHz or above, so short bursts such as opening an app or scrolling start fast. Measured: 3.5 dropped frames per fling, 61 ms to the first Overview frame, glmark2 3188; in exchange the tablet draws about 18% more power while scrolling and about 47% more under full GPU load.
  - Power Saver: tasks with a CPU floor, such as a virtual machine's, are no longer crowded onto the two prime cores; with such a load simulated, total power drops from 3.9 W to 3.3 W.
  - Real-time threads such as audio and the compositor are no longer pushed to the highest frequency by default.
- **Faster virtual machines**: the CPU floor GunyahVM gives virtual-machine threads takes effect from this release. On the 8 Pro, glmark2 in a Linux guest rises from 313 to 952 in Balanced and reaches 1869 in Performance, above the 1344 the host itself scores in Balanced.
- **New installations include GunyahVM 1.5.0**: installed systems already received it through Software Updater.
- **Kernel**:
  - If a driver hangs during suspend, the tablet now restarts by itself after about a minute instead of staying on a black screen until a long press of the power key.
  - The UFS storage's inline encryption engine is enabled, so file-system encryption (fscrypt) can run in hardware.
  - Bluetooth RFCOMM serial ports and the PAN network filters, as in Ubuntu's kernel.
  - Storage reads cost less CPU: at the same read speed, total CPU use drops by about 17% for random reads and about 64% for sequential reads.

## Upgrade notes

From 1.6.0 or 1.6.1: close your virtual machines, then update in Software Updater or run `sudo apt update && sudo apt full-upgrade`, and restart.

From 1.5.0 or earlier: run these commands once on the tablet to add the signed archive, then restart.

1. `wget -O piano-archive-keyring_1.1_all.deb https://github.com/yzddmr6/xiaomipad-8pro-mainline/releases/download/apt/piano-archive-keyring_1.1_all.deb`
2. `sudo apt install ./piano-archive-keyring_1.1_all.deb`
3. `sudo apt update && sudo apt full-upgrade`

## Known limitations

Balanced and Performance no longer cap the prime cores, but their 4.2 GHz and 4.32 GHz boost points are not used yet in this release: frequency scaling asks for at most 4.09 GHz.
