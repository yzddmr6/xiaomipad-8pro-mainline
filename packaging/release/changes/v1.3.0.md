主题：Linux 7.4-rc2 与本地 NPU 推理

Linux 7.4-rc2、NPU 推理与图形驱动更新。

## 更新

- **自动亮度**：在“设置 → 电源”中开启自动亮度，可按环境光调节屏幕背光。

- **内核更新**：使用 Linux 7.4-rc2 的设备支持与 GPU 恢复实现。
- **本地 NPU 演示**：预装运行库、模型和固件；`npu-demo` 可离线运行，长输入使用 NPU 预填充、CPU 生成。
- **图形驱动修复**：宿主和 Snap 图形运行时加入 Mesa 上游的同步对象、着色器和 A830v1 识别修复。
- **系统切换保护**：写入前核对电量与活动槽，失败时恢复完整启动镜像组。

- **传感器服务**：修复停止或重启时可能发生的退出崩溃。

- **硬件录屏**：GNOME 内置整屏录制默认使用 Iris 硬件编码，降低录屏进程的 CPU 占用。

- **虚拟机**：GunyahVM 1.2.0 支持 Linux 和 Windows 来宾。

## 升级须知

先将 packages 和 rollback 两个 ZIP 解压到同一目录。

使用完整软件包批次升级并重启；整版回退同时恢复用户态与启动镜像。升级前请正常关闭正在运行的虚拟机。

## 已知限制

在 2× 桌面缩放下，虚拟机窗口可能裁切来宾画面的右侧和底部。

默认硬编录屏文件可能比软件编码大。

NPU 演示默认面向随附小模型；短输入使用 CPU，不会将其他应用自动切换到 NPU。

Theme: Linux 7.4-rc2 and local NPU inference

Linux 7.4-rc2, NPU inference and graphics driver updates.

## Changes

- **Automatic brightness:** Enable Automatic Brightness in Settings → Power to adjust the backlight to ambient light.

- **Kernel update:** Linux 7.4-rc2 device support and GPU recovery.
- **Local NPU demo:** The runtime, model and firmware are preinstalled. `npu-demo` runs offline, using NPU prefill and CPU generation for long prompts.
- **Graphics fixes:** Both host and Snap graphics include upstream Mesa syncobj, shader and A830v1 identification fixes.
- **System-switch safeguards:** Check battery and active-slot evidence before writing, restoring the complete boot set on failure.

- **Sensor service:** Fix a shutdown crash when stopping or restarting the service.

- **Hardware screen recording:** GNOME’s built-in full-screen recorder uses the Iris hardware encoder by default, reducing recorder CPU use.

- **Virtual machines:** GunyahVM 1.2.0 supports Linux and Windows guests.

## Upgrade notes

Extract the packages and rollback ZIP files into the same directory.

Upgrade the complete package batch and reboot. Complete rollback restores userspace and boot images together. Shut down running virtual machines before upgrading.

## Known limitations

At 2× desktop scaling, a VM window may clip the right and bottom edges of the guest display.

The default hardware recording settings can produce larger files than software encoding.

The default NPU demo targets the included small model. Short prompts use the CPU; other applications are not automatically offloaded to the NPU.
