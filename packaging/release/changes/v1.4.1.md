主题：升级清理与充电保护

整组升级后自动清理旧版本留下的文件，只用平板就能升级，切换不再看电量，GunyahVM 升到 1.3.0，充电增加两项原厂保护。

## 更新

- **升级不留残留**：整组升级或回退完成后，自动清掉旧的发布批次、旧内核、旧启动镜像备份和不再使用的旧包，只保留当前版本和用于回退的上一版。从旧版本升上来的机器会一次清掉历次累积的旧文件。
- **GunyahVM 1.3.0**：系统自带的 GunyahVM 升到 1.3.0，可以在平板上直接从 Apple 的服务器创建 macOS 虚拟机，并合成一个安装包。
- **只用平板也能升级**：升级说明改成全程在平板上完成：用 Firefox 下载软件包，在终端里校验、预览清理、运行安装器，不再需要电脑。
- **切换和安装不看电量**：在 Linux 和 Android 之间切换、安装和升级都不再要求最低电量。
- **电量计告警时降流**：任一颗电量计报告电芯内短路或超出安全工作区时，按原厂把充电电流降到八成。
- **USB-C 进液保护**：充电口检测到液体时保持 5 V、不进电荷泵，干了以后自动恢复快充。

## 升级须知

升级只用平板即可完成：在平板上下载软件包和回退两个附件，校验、解压后整组升级，使用 `piano-1.4.1` 和 `--previous piano-1.4.0-rollback-1.4.1`，步骤见升级指南。升级前关闭虚拟机，完成后重启。

## 已知限制

清理后只保留本次升级的新旧两批，整版回退只能回到上一版。其他已装软件仍依赖的旧项目包和改过的配置文件会保留，原因记在 `cleanup.json`。

Theme: Upgrade cleanup and charging protection

Whole-release upgrades clear what earlier versions left behind and need only the tablet, switching no longer depends on the charge, GunyahVM moves to 1.3.0, and charging gains two stock protections.

## Changes

- **No leftovers after upgrades**: after a full upgrade or a rollback, old release batches, old kernels, old boot image backups and packages that are no longer used are removed automatically; only the current version and the previous one kept for rollback remain. Tablets upgraded from earlier versions clear everything accumulated so far in one go.
- **GunyahVM 1.3.0**: the bundled GunyahVM is now 1.3.0, which creates macOS VMs on the tablet directly from Apple's servers and ships as a single package.
- **Upgrade on the tablet alone**: the upgrade guide now runs entirely on the tablet: download the package in Firefox, then verify it, preview the cleanup and run the installer in the terminal; no computer is needed.
- **Switch and install at any charge**: switching between Linux and Android, installing and upgrading no longer require a minimum battery level.
- **Lower current on gauge alerts**: when either fuel gauge reports an internal short or a safe-operating-area alert, charging current drops to 80 %, as the stock firmware does.
- **USB-C moisture protection**: while liquid is detected in the charging port, charging stays at 5 V without the charge pump, and fast charging resumes once the port is dry.

## Upgrade notes

The upgrade needs only the tablet: download the package and rollback attachments on it, verify and extract them, then run the whole-release upgrade with `piano-1.4.1` and `--previous piano-1.4.0-rollback-1.4.1` as the upgrade guide describes. Shut down virtual machines before upgrading and reboot afterwards.

## Known limitations

After the cleanup only the two batches of the latest upgrade remain, so a whole-release rollback returns to the previous version only. Earlier project packages that other installed software still needs, and changed configuration files, are kept; `cleanup.json` records why.
