本版更新设备功能与维护工具。

## 更新

- **快充**：支持原装适配器的 PPS 快充，充电电流随电量和温度自动调整，并保留“保护电池健康”功能。
- **快速挂起**：亮屏后立即挂起时，不再被键盘立即唤醒。
- **光感上报**：修复光感启停时可能停止上报读数的问题。
- **后置补光**：支持后置补光灯常亮控制，并提供核对读回、恢复原设置的检查工具。
- **图形驱动**：更新到 Mesa 26.2.6，包含上游的同步、渲染与并发修复。
- **更新提醒**：有新版本时在桌面显示提醒，可在通知设置中关闭。
- **Firefox 迁移**：从 snap 版 Firefox 迁移时保留已有的用户资料。
- **原厂恢复文档**：新增从 Ubuntu 双系统恢复 HyperOS 的[文档与离线准备工具](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v1.1.1/docs/RESTORE-STOCK.md)，用于检查本机 GPT 备份并生成恢复片段，工具不执行设备刷写。

## 已知限制

- PPS 快充需要兼容的适配器与线缆，实际功率受电量、温度及电池保护设置影响。
- 常亮补光通过系统 LED 接口控制，相机应用中的闪光按钮需要由应用接入。
- 完整恢复原厂系统会清除 Android 和 Ubuntu 数据，必须使用本机安装前的备份；其他设备的备份不能替代。

Device and maintenance-tool updates.

## Changes

- **Fast charging**: PPS fast charging with the original adapter adjusts current automatically with charge level and temperature, while retaining Preserve Battery Health.
- **Suspend after waking the screen**: Suspending right after turning the screen on no longer wakes the tablet immediately through the keyboard.
- **Ambient-light readings**: Fixes ambient-light readings stopping when the sensor is switched on and off.
- **Rear torch**: Adds rear torch control and a check tool that verifies readback and restores the previous setting.
- **Graphics drivers**: Updates Mesa to 26.2.6, including upstream synchronization, rendering and concurrency fixes.
- **Update notifications**: Shows a desktop notification when a new release is available; notifications can be disabled in settings.
- **Firefox migration**: Preserves existing user data when migrating from the Firefox snap.
- **Stock recovery documentation**: Adds [documentation and an offline preparation tool](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v1.1.1/docs/RESTORE-STOCK.en.md) for restoring HyperOS from an Ubuntu dual-boot installation; the tool checks the tablet’s own GPT backups and extracts restoration regions without flashing the device.

## Known limitations

- PPS fast charging requires a compatible adapter and cable; actual power depends on charge level, temperature and battery-protection settings.
- Torch control is exposed through the system LED interface; camera applications need to integrate their own flash controls.
- A full stock restoration erases Android and Ubuntu data and requires this tablet’s own pre-installation backups; backups from another tablet cannot substitute for them.
