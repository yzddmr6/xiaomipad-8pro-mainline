主题：图形加速与整版回退

本版修复沙箱程序的 GPU 加速，更新设置，并提供整版回退；内核仍为 Linux 7.2.15。

## 更新

- **沙箱图形加速**：使用宿主图形库的浏览器内核等沙箱程序也能使用 Adreno 830，不再因驱动路径退回软件渲染。
- **Vulkan 设备列表**：Adreno 830 只显示一次，避免重复设备影响选择。
- **系统设置**：控制中心更新至 50.3，继续支持将电源键设为锁屏。
- **整版回退**：用户态软件包与启动镜像成组恢复，图形界面故障时也能通过开发者 SSH 执行回退。
- **虚拟机图形**：配套 GunyahVM 1.1.0，让 Linux 来宾继续使用 GPU 加速。

## 升级须知

- **整组升级**：先正常关闭虚拟机，再按升级指南安装本版完整批次并重启，无需重分区或重装系统。
- **回退副本**：升级附件同时提供上一版批次；保留完整新旧软件包和启动镜像，单独换回旧启动镜像不能恢复用户态。
- **Snap 应用**：独立图形运行时保持不变，新装应用仍按图形提供者说明连接。

## 已知限制

本版没有新增使用限制。

Theme: Graphics acceleration and complete release rollback

This release fixes GPU acceleration in sandboxed applications, updates Settings and adds complete release rollback; the kernel remains Linux 7.2.15.

## Changes

- **Sandboxed graphics acceleration:** Browser engines and other sandboxes that use host graphics libraries can use Adreno 830 instead of falling back to software rendering because of driver paths.
- **Vulkan device list:** Adreno 830 appears once, avoiding duplicate devices during selection.
- **System Settings:** Control Center is updated to 50.3 while retaining the power-button lock option.
- **Complete release rollback:** Userspace packages and boot images are restored together, with developer-mode SSH available when the graphical interface fails.
- **Virtual-machine graphics:** GunyahVM 1.1.0 keeps Linux guests GPU accelerated with the updated graphics packages.

## Upgrade notes

- **Complete upgrade:** Shut down virtual machines normally, install the complete batch following the upgrade guide and reboot; no repartitioning or reinstallation is needed.
- **Rollback copy:** The upgrade attachment also supplies the previous batch; retain both package batches and boot sets, as restoring boot images alone cannot restore userspace.
- **Snap applications:** Independent graphics runtimes remain unchanged; connect newly installed applications as described in the graphics-provider guide.

## Known limitations

No additional usage limitations in this release.
